# Heretical Documentation {#mainpage}

This portal aggregates the maintained documentation of the Heretical workspace and
its registered products. It is generated by [Doxygen](https://www.doxygen.nl/) with the
[Doxygen Awesome](https://jothepro.github.io/doxygen-awesome-css/) theme from exact,
pinned source revisions. Canonical documentation stays in each owning repository; this
site publishes selected documents and preserves their relative links and media.

Navigate with the tree on the left or the search box above. The
[source provenance](provenance.md) page records the exact revisions used to build a given
publication.
